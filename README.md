# WearTake Store — JavaScript Fashion Catalog

An interactive front-end storefront built with **HTML, CSS, and vanilla JavaScript**, featuring a searchable product catalog, category filters, and a browser-local shopping cart.

**[▶ See Project Live ↗](https://weartake-store-preview-p5a6fmro4-pedrohenriquebarrosns-projects.vercel.app/)** — updated public preview.

## Features

- Browse a responsive six-item sample catalog.
- Search products and filter by category.
- Add and remove cart items, and adjust quantities.
- Retain cart contents in the browser using local storage.

## Technologies

HTML5 · CSS3 · JavaScript · localStorage

## Version

The live preview is from the [updated review branch](https://github.com/pedrohenriquebarrosn/WearTake-Store/tree/review/deep-code-audit-20261013). The default `master` branch may differ until merged. This is a front-end demonstration with illustrative products, not a checkout or order-processing service.
